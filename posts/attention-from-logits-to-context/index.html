A derivation of scaled dot-product and multi-head attention, including variance, masking, gradients, and computational cost.
Author

Diego Filippo Marino

Published

August 13, 2026

The compact formula for attention hides three separate operations: a learned similarity metric, a row-wise probability model, and a content lookup. Pulling those pieces apart is useful because most later improvements change only one of them.

The operation and its shapes

Let a sequence be represented by X\in\mathbb{R}^{n\times d_{\text{model}}}. A single head forms

Q=XW^Q,\qquad K=XW^K,\qquad V=XW^V,

where Q,K\in\mathbb{R}^{n\times d_k} and V\in\mathbb{R}^{n\times d_v}. Scaled dot-product attention is (Vaswani et al. 2017)

S=\frac{QK^\top}{\sqrt{d_k}},\qquad P=\operatorname{softmax}_{\text{row}}(S+M),\qquad O=PV. \tag{1}

The score S_{ij} measures how strongly query position i selects key position j. Each row of P is a categorical distribution. The output o_i is therefore a data-dependent convex combination of value vectors.

For causal self-attention, the mask is

M_{ij}=\begin{cases} 0,&j\le i,\\ -\infty,&j>i. \end{cases}

Adding the mask before softmax makes every illegal probability exactly zero in ideal arithmetic. In finite precision, implementations use either negative infinity or a sufficiently negative representable value.

Why divide by \sqrt{d_k}?

Suppose the components of q and k are independent, centered, and have unit variance. Then

\operatorname{Var}(q^\top k) =\operatorname{Var}\left(\sum_{r=1}^{d_k}q_rk_r\right) =d_k.

The unscaled logit has standard deviation \sqrt{d_k}. As the head dimension grows, the largest logit tends to dominate the softmax, reducing its entropy and concentrating the Jacobian near zero. Scaling restores an order-one logit variance.

import numpy as np
import matplotlib.pyplot as plt

plt.style.use("../../eigenholm.mplstyle")

rng = np.random.default_rng(7)
dims = np.array([8, 16, 32, 64, 128, 256, 512])
entropy_scaled, entropy_raw = [], []

for d in dims:
    q = rng.normal(size=(400, d))
    k = rng.normal(size=(400, 64, d))
    logits = np.einsum("bd,bnd->bn", q, k)
    for values, scale in ((entropy_raw, 1.0), (entropy_scaled, np.sqrt(d))):
        z = logits / scale
        z -= z.max(axis=1, keepdims=True)
        p = np.exp(z)
        p /= p.sum(axis=1, keepdims=True)
        values.append(np.mean(-np.sum(p * np.log(p + 1e-30), axis=1)))
Plotting code 
fig, ax = plt.subplots(figsize=(7, 3.6))
ax.plot(dims, entropy_raw, "o-", label="unscaled")
ax.plot(dims, entropy_scaled, "o-", label=r"scaled by $\sqrt{d_k}$")
ax.axhline(np.log(64), color="0.55", lw=1, ls=":", label="uniform entropy")
ax.set(xscale="log", xlabel=r"head dimension $d_k$", ylabel="entropy (nats)")
ax.legend()
plt.show()

The experiment is deliberately distributional rather than model-specific. It isolates the argument behind the normalization in Equation 1: without it, increasing width changes the effective temperature of attention.

The softmax Jacobian

For one row p=\operatorname{softmax}(s),

\frac{\partial p_i}{\partial s_j}=p_i(\delta_{ij}-p_j), \qquad J_{\text{softmax}}=\operatorname{diag}(p)-pp^\top. \tag{2}

This matrix is positive semidefinite and has a null direction along the all-ones vector. Adding a constant to every logit does not change the distribution.

Two scalar summaries of Equation 2 explain the previous section quantitatively. Its trace is

\operatorname{tr}(J_{\text{softmax}}) =\sum_ip_i(1-p_i) =1-\|p\|_2^2, \tag{3}

and its spectral norm is bounded by \max_ip_i. Both vanish as the row approaches a one-hot vector, where \|p\|_2^2\to1. The collapse is not a numerical accident that better precision could fix; it is the derivative of a function that has become locally constant. A row that has committed to one key cannot report how it would have preferred a different key, so no gradient signal flows back to the logits that produced the commitment.

This gives the \sqrt{d_k} argument teeth. The scaling is not cosmetic normalization: it keeps \|p\|_2^2 away from one at initialization, and Equation 3 is the quantity it protects. It also explains why entropy is the right diagnostic to plot. Entropy and 1-\|p\|_2^2 are different measures of the same concentration, and the second is proportional to the gradient the row can still transmit.

The same invariance explains the standard stable implementation

def softmax(x, axis=-1):
    shifted = x - x.max(axis=axis, keepdims=True)
    weights = np.exp(shifted)
    return weights / weights.sum(axis=axis, keepdims=True)

Subtracting the maximum changes neither P nor the gradient, but prevents overflow in the exponential.

Multi-head attention is a structured factorization

With h heads,

\operatorname{MHA}(X) =\operatorname{Concat}(O_1,\ldots,O_h)W^O,

where each O_r has its own projected queries, keys, and values. For the common choice d_k=d_v=d_{\text{model}}/h, the projection and attention FLOP counts remain approximately constant as h changes:

\underbrace{4nd_{\text{model}}^2}_{Q,K,V,O\text{ projections}} +\underbrace{2n^2d_{\text{model}}}_{QK^\top\text{ and }PV}.

Heads do not provide free capacity. They partition the channel dimension into several learned similarity spaces. Very small d_k constrains each compatibility function, while a single wide head forces one attention distribution to serve every subspace.

What a head can and cannot express

The constraint imposed by small d_k can be made precise. Since S=QK^\top/\sqrt{d_k} is a product through a d_k-dimensional space,

\operatorname{rank}(S)\le d_k, \tag{4}

no matter how long the sequence is. At n=4096 and d_k=64, a head chooses its score matrix from a set of measure zero inside \mathbb R^{n\times n}. Softmax then acts row-wise, and because each row is invariant to an additive constant, the reachable set is described by row-centered logit matrices of rank at most d_k.

That immediately raises a question the formula cannot answer on its own: which attention patterns actually need many dimensions? Some familiar ones need remarkably few.

n = 128
i, j = np.arange(n)[:, None], np.arange(n)[None, :]
pairing = rng.permutation(n)

targets = {
    "distance decay": -np.abs(i - j) / 8.0,
    "periodic, period 16": 3 * np.cos(2 * np.pi * (i - j) / 16),
    "content match (random)": rng.normal(size=(n, n)),
    "arbitrary pairing": 6.0 * (j == pairing[:, None]),
}

head_dims = np.array([1, 2, 4, 8, 16, 32, 64])

# Best rank-r approximation error in Frobenius norm is the norm of the discarded
# singular values, so the whole curve comes from one spectrum per target.
residual = {}
for name, target in targets.items():
    centered = target - target.mean(axis=1, keepdims=True)   # row shifts are free
    spectrum = np.linalg.svd(centered, compute_uv=False)
    tail = np.sqrt(np.cumsum(spectrum[::-1] ** 2)[::-1]) / np.linalg.norm(centered)
    residual[name] = tail[head_dims]
Plotting code 
fig, ax = plt.subplots(figsize=(7, 3.8))
for name, tail in residual.items():
    ax.semilogy(head_dims, np.maximum(tail, 1e-6), "o-", ms=4, label=name)
ax.set_xscale("log", base=2)
ax.set(xlabel=r"head dimension $d_k$",
       ylabel="relative error of best rank-$d_k$ fit", ylim=(5e-7, 3))
ax.axhline(1e-6, color="0.6", lw=0.8, ls=":")
ax.text(1.05, 1.4e-6, "exact (clipped)", fontsize=7, color="0.4")
ax.legend(fontsize=8)
plt.show()

The periodic pattern is exactly rank two, because \cos\left(\omega(i-j)\right)=\cos\omega i\cos\omega j+\sin\omega i\sin\omega j. One frequency of relative position costs one coordinate pair, which is precisely the accounting behind rotary embeddings. A smooth distance bias is nearly as cheap: eight dimensions reproduce it to about two percent.

An arbitrary pairing is the opposite. Sending each query to one unrelated key is essentially a permutation matrix, and 64 dimensions still leave 70 percent of it unexplained. Nothing about that pattern is complicated to describe; it is simply incompressible, and Equation 4 is a compression budget.

This is the honest version of the claim that attention is a lookup table. It is a lookup table whose addressing function must factor through d_k dimensions. Structured, reusable relations are affordable, arbitrary correspondences are not, and the useful patterns of language mostly live at the cheap end. It is also the reason heads are the right unit of capacity: h heads give a sum of h separately softmaxed rank-d_k operators, which is a strictly richer object than one rank-hd_k operator (Bhojanapalli et al. 2020).

Memory is not the same as arithmetic

The two matrix multiplications require O(n^2d) arithmetic. A literal implementation also writes S and P, each with n^2 entries. At sequence length 16,384, one FP16 matrix for one batch-head pair occupies 512 MiB. The quadratic intermediate, not only the quadratic FLOP count, is the systems problem.

This distinction leads directly to IO-aware kernels such as FlashAttention: equation Equation 1 stays unchanged, but its evaluation order is reorganized so that S and P never reside in high-bandwidth memory as complete matrices.

What the equation does not guarantee

Attention weights are conditional routing coefficients, not a causal explanation. A high value of P_{ij} says that value v_j contributes strongly to output o_i under the current parameterization. Residual connections, value projections, later layers, and correlated features complicate any interpretation beyond that statement.

The normalization also creates competition. Increasing one logit decreases other probabilities in the row, even when those keys are unrelated. This coupling is useful for selection, but it means that attention is not a set of independent relevance scores.

Practical checks

A minimal implementation should satisfy three invariants:

  1. Every unmasked row sums to one within numerical tolerance.
  2. Masked probabilities are zero.
  3. Shifting a complete score row by any scalar leaves the output unchanged.

Those tests catch axis errors and many masking mistakes before they become training pathologies.
