Colophon

Eigenholm is an independent technical website and research notebook maintained by Diego Filippo Marino.

Purpose

This site publishes research notes, paper analyses, implementation details, and technical experiments. The goal is to think carefully about problems in machine learning, mathematics, and scientific computing, then document what is learned along the way.

Articles here are written for a technical audience. They aim to be precise, reproducible, and useful.

Tools

This site is built with Quarto, an open-source scientific publishing system. Mathematics is rendered with KaTeX. Code is executed in Python via Jupyter kernels.

The source is version-controlled with Git and hosted on GitHub. Deployment is automated through GitHub Actions to GitHub Pages.

Typography

Headings use Source Serif 4. Body text uses Inter, a typeface designed for computer screens. Code uses a system-oriented monospace stack headed by Cascadia Code and JetBrains Mono.

Design

The visual identity is intentionally restrained: generous whitespace, a muted teal accent, clear hierarchy, and minimal decoration. The coordinate-dot motif references the mathematical meaning of eigen: characteristic values, fixed points, and structure.

Eigenholm is an independent technical website and research notebook maintained by Diego Filippo Marino.

## Purpose

This site publishes research notes, paper analyses, implementation details, and technical experiments. The goal is to think carefully about problems in machine learning, mathematics, and scientific computing, then document what is learned along the way.

Articles here are written for a technical audience. They aim to be precise, reproducible, and useful.

## Tools

This site is built with [Quarto](https://quarto.org), an open-source scientific publishing system. Mathematics is rendered with [KaTeX](https://katex.org). Code is executed in Python via Jupyter kernels.

The source is version-controlled with Git and hosted on [GitHub](https://github.com/DiegoFilippoMarino/Eigenholm). Deployment is automated through GitHub Actions to GitHub Pages.

## Typography

Headings use [Source Serif 4](https://fonts.google.com/specimen/Source+Serif+4). Body text uses [Inter](https://rsms.me/inter/), a typeface designed for computer screens. Code uses a system-oriented monospace stack headed by Cascadia Code and JetBrains Mono.

## Design

The visual identity is intentionally restrained: generous whitespace, a muted teal accent, clear hierarchy, and minimal decoration. The coordinate-dot motif references the mathematical meaning of *eigen*: characteristic values, fixed points, and structure.

## Citing articles

Each article on this site includes automatically generated citation metadata. Use the citation appendix at the bottom of any article to reference it in your own work.
